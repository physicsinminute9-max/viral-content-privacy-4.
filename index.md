
# Privacy Policy – Viral Content Autopilot

Last updated: November 22, 2026

## Overview

Viral Content Autopilot is a personal content creation and publishing tool operated by Aliza Walace.

## Information and Account Access

This tool accesses only the owner's authorized Facebook Page and Pinterest Business account through their official APIs.

It may use account identifiers, authorized access tokens, and selected board information to perform the requested publishing tasks.

## How Information Is Used

Information is used only to generate and publish content to the owner's selected social media accounts.

We do not sell or share personal information or API data with third parties for advertising.

## Security

API credentials are stored as private GitHub Actions repository secrets and are not intentionally included in generated posts or public source files.

## Third-Party Services

This tool uses services provided by Meta, Pinterest, and GitHub. Their own privacy policies and terms apply to their services.

## Data Retention

This tool does not intentionally maintain a separate database of Pinterest user information. Generated images and workflow logs may be retained by GitHub according to repository and Actions settings.

## Contact

For privacy questions, contact the app owner through the contact information associated with the developer account.
